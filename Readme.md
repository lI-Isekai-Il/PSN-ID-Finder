# PSN Online ID Finder

PSN Online ID Finder is a simple tool and efficient tool that assists users in checking the availability of PlayStation Network Online IDs.

The project is intended to provide a fast and clear workflow for searching IDs, with an emphasis on usability and minimal overhead.

For the best user experience, it is recommended to use the precompiled application available in the
[Releases](https://github.com/lI-Isekai-Il/PSN-ID-Finder/releases) section.
